CHANGES MADE IN THIS ADAPTATION / 本モデルで加えた主な変更
----------------------------------------------------------------
- Outer skin / hair removed to produce an écorché (musculature shown).
  外皮・毛髪を除去し écorché 化（筋層を表示。眼球・帽状腱膜は保持）
- Trilingual labels added as custom properties and index
  (Japanese / English / Latin, TA/FMA-based) on all 931 parts.
  全931パーツに3言語ラベル（日本語/英語/ラテン語）をカスタムプロパティ
  ＋索引で付与
- Heavy meshes given a non-destructive Decimate modifier for usable file
  sizes (full resolution recoverable by disabling it).
  重いメッシュに非破壊のDecimateを付与（無効化でフル解像度に復元可）
- Delivered as a pure static model in A-pose (no rig).
  純静的・A-pose で提供（リグなし）
- Multi-format packaging (.blend / .glb / .fbx / .obj) + name index.
  多形式パッケージ化＋解剖名索引
